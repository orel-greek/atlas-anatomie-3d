# Atlas d'anatomie 3D

Atlas d'anatomie 3D en français, dans le navigateur : squelette, muscles, système
nerveux (moelle épinière et ses faisceaux, nerfs du membre inférieur), avec une
fiche de vulgarisation pour les principales structures. Lisible sur ordinateur,
tablette et téléphone.

Ce dépôt ne contient que le site construit, publié par GitHub Pages.
